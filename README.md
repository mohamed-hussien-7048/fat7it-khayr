موقع قهوة فتحة خير.. تجربة تفاعلية بتنقلك لأجواء القعدة البلدي والروقان بلمسة عصري. 

___________________________________________________________________________________________________________________________
 فكرة المشروع

الموقع مربوط بـ Google Sheets عشان صاحب القهوة يغير الأسعار أو يزود المشروبات بسهولة من موبايله بدون ما يرجع للمبرمج.

___________________________________________________________________________________________________________________________
 صفحات الموقع

الرئيسية (index.html): الواجهة وباب الدخول.
البارد (menu1.html): عصائر ومشروبات ساقعة.
الساخن (menu2.html): القهوة، الشاي، والمشروبات الدافية.
جلسات الدخان (menu3.html): الشيشة والأجواء.
القعدة الحلوة (gallery.html): معرض صور المكان.
العنوان والتواصل (location.html & contact.html): اللوكيشن وأرقام الإدارة.
